A **palindrome** reads the same forwards and backwards. Given a string `s`,
return its **longest contiguous substring that is a palindrome**.

If several palindromic substrings share the maximum length, return the one
that **starts earliest** in `s`.

## Example 1

```
s      = "banana"
output = "anana"
```

## Example 2

```
s      = "abcd"
output = "a"    # every single letter is a palindrome; "a" starts first
```

## Constraints

- `1 <= len(s) <= 1000`
- `s` contains only lowercase English letters
