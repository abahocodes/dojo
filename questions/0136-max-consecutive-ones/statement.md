You are given an array `nums` in which every element is either `0` or `1`.
Return the length of the longest stretch of adjacent elements that are all
`1`. If `nums` contains no `1`, return `0`.

## Example 1

```
nums   = [1, 0, 1, 1, 1, 0, 1, 1]
output = 3    # positions 2..4
```

## Example 2

```
nums   = [0, 1, 1, 0, 0, 1]
output = 2
```

## Constraints

- `1 <= len(nums) <= 10^5`
- Every `nums[i]` is `0` or `1`.
