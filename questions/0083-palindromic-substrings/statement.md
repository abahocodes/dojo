Count the substrings of `s` that are palindromes, meaning they read the same
forwards and backwards. A substring is a non-empty run of consecutive
characters. Substrings at different positions are counted separately, even if
they contain the same characters.

## Example 1

```
s      = "aba"
output = 4      # "a", "b", "a", "aba"
```

## Example 2

```
s      = "aaa"
output = 6      # "a" three times, "aa" twice, "aaa" once
```

## Constraints

- `1 <= len(s) <= 1000`
- `s` contains only lowercase English letters.
