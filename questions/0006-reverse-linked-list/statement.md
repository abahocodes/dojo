You are given `head`, the first node of a singly linked list (or `None` if the
list is empty). Each node has a value `val` and a pointer `next`.

Reverse the list by re-linking its nodes, and return the head of the reversed
list.

## Example 1

```
head   = 4 -> 9 -> 1 -> 7
output = 7 -> 1 -> 9 -> 4
```

## Example 2

```
head   = 3
output = 3
```

## Constraints

- The list has between `0` and `5000` nodes.
- `-5000 <= node.val <= 5000`

**Follow-up:** can you write both an iterative and a recursive version?
