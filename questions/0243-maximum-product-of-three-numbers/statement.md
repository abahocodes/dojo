Given an integer array `nums`, choose three elements at three different
positions and multiply them together. Return the largest product you can get.

The values may be negative or zero.

## Example 1

```
nums   = [2, 7, 3, 5]
output = 105   # 7 * 5 * 3
```

## Example 2

```
nums   = [-8, -6, 1, 4]
output = 192   # (-8) * (-6) * 4
```

## Constraints

- `3 <= len(nums) <= 10^4`
- `-1000 <= nums[i] <= 1000`
