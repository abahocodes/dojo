Given a string `s`, find the leftmost character that occurs in `s` **exactly
once** and return its index (0-based). If every character repeats, return
`-1`.

## Example 1

```
s      = "swiss"
output = 1      # 'w' is the only letter that appears once
```

## Example 2

```
s      = "abab"
output = -1
```

## Constraints

- `1 <= len(s) <= 10^5`
- `s` contains only lowercase English letters.
