Given a list of strings `strs`, return the longest string that every element
of `strs` starts with. If the strings share no first letter, return the empty
string `""`.

## Example 1

```
strs   = ["interview", "internal", "interval"]
output = "inter"
```

## Example 2

```
strs   = ["apple", "banana"]
output = ""
```

## Constraints

- `1 <= len(strs) <= 200`
- `0 <= len(strs[i]) <= 200`
- Strings contain only lowercase English letters.
