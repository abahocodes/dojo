Given a string `s`, return the string obtained by reversing the order of its
**English letters** (`a`-`z` and `A`-`Z`) while every other character stays at
exactly the same index.

## Example 1

```
s      = "ab-cd"
output = "dc-ba"
```

## Example 2

```
s      = "Go!2-it=Now"
output = "wo!2-Nt=ioG"
```

## Constraints

- `1 <= len(s) <= 100`
- Every character of `s` has an ASCII code from 33 to 122 (no spaces).
