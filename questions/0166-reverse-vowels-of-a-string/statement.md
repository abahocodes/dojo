Given a string `s`, return the string formed by reversing the order of its
**vowels** while every other character keeps its position.

The vowels are `a`, `e`, `i`, `o`, `u` and their uppercase forms. A vowel
keeps its case as it moves (an `A` stays an `A`).

## Example 1

```
s      = "education"
output = "odicatuen"   # vowels e,u,a,i,o become o,i,a,u,e
```

## Example 2

```
s      = "Hello, World!"
output = "Hollo, Werld!"
```

## Constraints

- `1 <= len(s) <= 3 * 10^5`
- `s` consists of printable ASCII characters (codes 32 to 126).
