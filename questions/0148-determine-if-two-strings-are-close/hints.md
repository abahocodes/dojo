# Hints

## Hint 1
Repositioning means the order of the characters never matters. Describe each
string by how many times each letter occurs.

## Hint 2
A relabel exchanges the counts of two letters that are both present. It can
never introduce a letter that is absent, nor remove one that is present.

## Hint 3
The strings are close exactly when they use the same set of letters and the
sorted lists of letter counts are equal. Two arrays of 26 counters are enough.
