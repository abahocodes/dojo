# Hints

## Hint 1
The positions of letters do not matter, only how many of each letter you
have.

## Hint 2
One copy of `"balloon"` uses one `b`, one `a`, two `l`, two `o` and one `n`.
How many copies does each letter alone allow?

## Hint 3
Count the five letters. The answer is the minimum of `b`, `a`, `l // 2`,
`o // 2` and `n`.
