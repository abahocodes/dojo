Given an integer array `arr`, count how many times each distinct value
occurs. Return `true` if no two distinct values occur the same number of
times, and `false` otherwise.

## Example 1

```
arr    = [8, 3, 8, 3, 3, 1]
output = true    # 3 occurs 3 times, 8 twice, 1 once
```

## Example 2

```
arr    = [5, -5, 0, 5, -5]
output = false   # 5 and -5 both occur twice
```

## Constraints

- `1 <= len(arr) <= 1000`
- `-1000 <= arr[i] <= 1000`
